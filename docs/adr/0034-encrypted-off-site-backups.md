# ADR 0034: Encrypted copies off the VPS: database, validator identity, keys

- Status: accepted (2026-11-23)
- Decided by: Claude, building block 3 (M11) under ADR 0030, which Diego confirmed. The bucket and
  the age key pair need Diego's accounts. Diego confirmed it on 2026-11-23: "confirmo todos los
  adrs".

## Context
The daily dump (ADR 0028) stays on the VPS, and nothing backed up the validator's identity, the key
files or `deploy/.env`. Losing the machine would lose the database, the keys that control the chain
and the contracts, and the validator that keeps ZyrcleChain alive.

## Decision
- **Encrypt before anything leaves.** `age` encrypts to a public key kept in `deploy/.env`; the
  private key is generated by Diego on his own machine and kept only by him, offline (a password
  manager and paper). The VPS cannot read its own copies.
- **Where:** an S3-compatible bucket, Cloudflare R2 by default (10 GB free, no fees to download),
  through `rclone`. The token reads and writes objects in that bucket only.
- **What:** the newest database dump every day, after `backup.sh`; every Sunday, or with
  `--keys`, a bundle of the validator identity (`staking/`: staking key, TLS certificate, BLS key;
  not the chain data, which the network can resync), the key files and `deploy/.env`.
- **Nothing installed on the host:** age and rclone run in a small Alpine image built on the VPS
  from `deploy/offsite/Dockerfile`, pinned by digest.
- **The script never deletes remote copies.** The bucket's lifecycle rule expires them (30 days for
  dumps, 12 weeks for key bundles) and a bucket lock keeps them from being deleted earlier, so a
  stolen token cannot wipe the backups.
- **Proven in CI:** `deploy/offsite-selftest.sh` runs the whole path against an S3 stand-in with a
  throwaway key and checks that what comes back decrypts to what went in, and that the chain data
  stays out.
- **A restore drill** (runbook 9.10) downloads, decrypts on Diego's machine and restores into a
  throwaway database with `backup.sh --check`.

## Consequences
- Losing the VPS loses at most a day of data and nothing that controls the chain.
- Losing Diego's private age key makes every copy unreadable; it needs two safe places.
- The keys bundle holds every key on the VPS, encrypted; whoever has both the bundle and the private
  key controls ZyrcleChain. Moving the admin powers to a multisig (M17) reduces what one key can do.
